in java è possibile l'uso delle **variabili condizione** in un interfaccia definita nella libreria:
```java
java.util.concurrent.locks
```


## Interfaccia Condition
```java
// metodi
public interface Condition{
 
	 void await() throws InterruptedException;
	 
	 void signal();
	 
	 void signalAll();
}
```
implementati con semantica **signal_and_continue** 


## Interfaccia Lock
```java
// metodi 
public interface Lock{
	
	void lock();
	
	void unlock();
	
	Condition newCondition(); 
}
```


## Utilizzo Interfacce 
per creare un oggetto Condition
```java
Lock lockvar= new ReentranLock();

Condition C= lockvar.newCondition(); 
```
C è una Condition associata all'interfaccia lockvar


## Monitor in Java
non esiste un costrutto equivalente in Java, ma si implementa il concetto

**Dati**:
- le _variabili condizione_
- _1 lock per la mutua esclusione_ dei metodi entry (da associare a tutte le var. condizione)
- variabili interne che rappresentano lo stato delle risorse

**Metodi**:
- public (entry)
- privati
- costruttori
